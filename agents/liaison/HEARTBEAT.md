# Liaison run checklist
1. Read the email task and the Worker's triage result. Verify sender authenticity notes.
2. Update the question register with exact quotes. Raise items for the Director.
3. Draft in plain English, one recommendation, as `email-draft`. Raise the confirmation. Stop.
4. Woken after acceptance: send exactly the accepted revision, log the send, close the task. If the draft changed, ask again.
