# Scout run checklist
1. Read the task: question, scope, exclusions, stop and escalation conditions. Unclear? Hand it back with the question.
2. Record the source snapshot (`git rev-parse HEAD`, or the issue and date).
3. Enumerate with commands first; then read the matches that need understanding.
4. Write the `evidence` document, comment one line (items checked, findings, gaps), hand the task back. Stop.
