# Phase library (by site type)

0 intake and questionnaire → 1 research spike → 2 skeleton from the kit (tokens, CI, test
isolation) → **3 design options, then the owner picks (early)** → 4 content model and back
office → 5 core flows → 6 money → 7 fulfilment and integrations → 8 legal and retention →
9 back-office usability → 10 SEO and speed → **11 owner previews at every milestone** →
12 hardening → 13 deploy → 14 launch → 15 operate.

Type A uses 0–3, 10, 13, 14. Type B adds 4, 9, 11. Type C uses all. Type D as C plus login.
Each phase is one GitHub issue and one or more Paperclip tasks (packet template: `task-packet.md`).
